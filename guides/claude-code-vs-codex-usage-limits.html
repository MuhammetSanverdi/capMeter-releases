Claude Code vs Codex: Usage Limits Compared

Guide · updated 2026-11-11

Two competing companies landed on almost the same design independently, which says something about the shape of the problem. The numbers differ, but the mechanism barely does — except for one difference that changes how you should use each tool, and that difference is shrinking.

The shared structure

Both meter usage in two layers: a short rolling window (5 hours) that catches an intense burst, and a longer weekly window as a backstop underneath it. Both sell larger tiers above the entry plan. On Claude's pricing page, Max gives 5x Pro usage and Ultra gives 10x Pro usage every week. OpenAI's ChatGPT Pro comes in three tiers at $100, $200 and $500 a month. Neither publishes a fixed message count, because actual cost depends on model and context length, not message count. If you've learned one system, you've basically learned the other's shape too.

The two have converged at the top end as well: the largest tiers drop the 5-hour window. Claude Ultra has no 5-hour limit for verified accounts, and OpenAI's Codex documentation says Pro plans currently have none. On those plans the weekly limit is the one that stops you.

The difference that matters: what shares the pool

Claude Code draws from the same account-level limits as claude.ai chat and Cowork — a long conversation in the browser and a long agent run in the terminal compete for the same budget. (Anthropic has adjusted Claude Code's weekly limit on its own, though: since September 14, 2026 it is 25% higher than before its summer promotion.)

Codex has worked differently. OpenAI's documentation says Codex shares its usage with ChatGPT Work, not with ordinary ChatGPT chat, so heavy chatting on chatgpt.com has not touched your Codex budget.

That changes in December. OpenAI says that from December, the allowance on Plus, Pro and Business plans will be shared across ChatGPT and Codex and measured in tokens, with Instant chat as the stated exception. After that, both companies work the same way in practice: heavy use of one product can leave less room for the other. If you do both heavily, watch both — on either side.

Getting more when you run out

Both now have a one-time, self-serve reset — if you have one waiting. Codex calls it a banked reset, which OpenAI grants periodically and you trigger yourself from Settings → Usage. Claude's version is a limit reset, which Anthropic gives "occasionally" to eligible plans; it refills your five-hour or weekly limit and is used from Settings → Usage in the web, desktop or mobile app, not from Claude Code in the terminal. Without one, nothing resets a Claude window early except the clock. Both platforms otherwise offer the same two fallbacks: pay-as-you-go credits billed at API rates once your plan limit is spent, and running the CLI against your own API key to remove the plan-based cap entirely.

Reset timing: one is documented, one is disputed

OpenAI states plainly that a banked reset changes your weekly anchor the moment you redeem it — the mechanism is explicit. Anthropic's weekly reset is murkier: it's supposed to land on a fixed day and time, but independent measurements and bug reports describe it arriving early often enough that the exact mechanism isn't something Anthropic has confirmed publicly.

If you use both

Nobody publishes a single number that averages "Claude limit" and "Codex limit" into one useful figure, because they're not the same currency and don't reset in sync. Watching them as two separate account-level percentages — rather than trying to mentally merge them — is the only approach that doesn't lie to you.
